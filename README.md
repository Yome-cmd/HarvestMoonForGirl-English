## How to patch (Windows)

1. Unzip `HMfG_English_Patch_v1.0.zip`.
2. Drag the Japanese `.bin` onto `HMfG_English_Patcher.exe` (or put the patcher in the same folder and double-click it).
3. It creates `Harvest Moon for Girl (English).bin` and `.cue` in the same folder.
4. Load the `.cue` in your emulator (DuckStation etc.) or burn it to a CD-R for a real PlayStation.
